# Contributing to DavidHiFi

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug

[Open an issue](https://github.com/DavidHiFi/davidhifi.github.io/issues/new) and include:

- what you did, what you expected and what happened instead
- your browser and device, for example Firefox on Windows or Safari on iPhone
- a screenshot of the problem

## Suggesting a change

Open an issue that says what you would change and why. A screenshot or a mock-up helps.

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. Run the site locally with `python -m http.server 8000` and open `http://localhost:8000`.
3. Check your change at phone, tablet and desktop widths, and make sure nothing scrolls sideways.
4. Keep each pull request to one change, and say in the description how you tested it.

Keep it plain: no framework, no build step and no files loaded from other sites. Colours come from the Catppuccin Mocha variables at the top of the stylesheet.
